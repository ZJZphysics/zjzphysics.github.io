# 北航物理学院高等量子力学课程小组研究

[GitHub Pages 公开入口](https://zjzphysics.github.io/) · [课程评分系统](https://buaa-advanced-quantum.linencrow.chatgpt.site/)

本仓库包含课程网站的源码。GitHub Pages 发布根目录的 `index.html`，并引导访问者进入运行中的课程网站。登录、评分、统计和课件交流由课程网站的服务端处理。

## 上课前

1. 打开网站，在页脚进入「课程管理」，用管理员密码登录。
2. 导入学生名单。支持上传 UTF-8 的 CSV、TSV、TXT，或从 Excel 复制后粘贴。名单可只含学号，也可以含「学号、组号」两列或「学号、姓名、组号」三列。组号填 1 到 8。学号有前导零时，把 Excel 单元格设为文本再粘贴。
3. 只导入学号时，可以为整批选择同一个组。暂不分组的学生仍可登录，分组后才能评分或上传课件。之后可通过带组号的名单补充分组。重新导入只含学号的名单并选择「暂不分组」时，已有组别会保留。
4. 在管理页填写各组汇报主题。完成分组的学生可以上传或更新本组的 PPT/PPTX，还可以附一份 PDF 供在线预览。

## 汇报现场

每一组汇报结束后，管理员点该组「开放评分」。学生只填学号即可登录，系统忽略字母大小写。学生独立提交 0–100 的整数分。系统按名册识别所属组，跳过自己组并限制每轮只提交一份。管理员核对有效份数和应评分人数后结束该轮，再开放下一组。

组均分 = 本组所有有效评分之和 ÷ 有效评分份数。八组全部评分结束后，全班总平均 = 八组均分之和 ÷ 8。显示与导出保留两位小数，计算使用原始精度。

管理员可下载组均分和实名评分明细两个 CSV。发布成绩后，登录学生可以查看各组均分和全班总平均。匿名访客只能看到课程首页和轮次状态。课件和课件文件名仅课程成员可见，实名明细仅管理员可见。

## 运行和维护

- 构建使用 Node.js 24。运行 `node build.mjs` 生成 `dist/server/index.js`，再运行 `node check.mjs` 执行独立的 SQLite 和对象存储模拟测试。
- 运行时使用 Cloudflare Worker、D1（`DB`）及 R2（`BUCKET`）。首次部署前按顺序应用 `drizzle/` 中的迁移。在托管平台将 `COURSE_ADMIN_PASSWORD` 配置为 24 字节随机值的无填充 Base64URL 字符串。
- 管理密码、名册、成绩及上传课件均属于运行数据。源码仓库只包含程序、空的数据结构和 8 个初始组别。
